# [TreePrep status](https://status.treeprep.com): <!--live status--> **🟩 All systems operational**

Uptime monitor and status page for [TreePrep](https://treeprep.com), built with [Upptime](https://upptime.js.org) (GitHub Actions, Issues and Pages). It checks the website, the API, the code runner and AI feedback, opens an issue when one of them breaks and closes it when it recovers.

## Setup and configuration

- Setup steps (token, secrets, Pages, DNS): [docs/SETUP.md](./docs/SETUP.md)
- Checks and status page settings: [.upptimerc.yml](./.upptimerc.yml)
- Theme and brand files: [assets/](./assets/)
- Files under `.github/workflows/`, `history/`, `api/` and `graphs/` are generated by Upptime; do not edit them by hand.
